# Medical Assistance Web App

A web application designed to help users **manage their medications and doctor appointments** efficiently. The app sends reminders for taking medicines on time and allows users to organize their medical schedule in one place.

## Features
- Add, edit, and delete medicine reminders
- Schedule and manage doctor appointments
- User-friendly interface for easy navigation
- Notifications to ensure timely medication intake
- Simple data storage with PHP backend

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: PHP
- Database: MySQL
